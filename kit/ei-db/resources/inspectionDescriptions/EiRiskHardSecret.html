코드에 박힌 비밀번호 · 키 · 토큰 · DB 접속 주소를 알려 줍니다. 소스와 함께 퍼지고, 바꾸려면 코드를 고쳐야 합니다. 
private String dbPassword = "tiger123";                       // ← 표시
String url = "jdbc:oracle:thin:@10.1.2.3:1521:ORCL";           // ← 표시
// 고친 모양
@Value("${spring.datasource.password}") private String dbPassword;

이름이 password · pwd · pw · secret · token · apiKey 같은 변수 · 대입 · setter · put("db.password", …) 의 문자열 값, 그리고 이름과 상관없이 호스트가 든 JDBC 주소, 「아이디:비밀번호@」 가 든 URL, 개인 키, AWS 접근 키를 봅니다.

설정 키(db.password), 상수 이름(DB_PASSWORD), 화면 경로, 문구, 4글자보다 짧은 값, 이름이 ~Param · ~Field · ~Label · ~Key 처럼 이름 · 설명을 담는 변수는 건너뜁니다. 테스트 소스와 설정 파일(application.yml 등)은 보지 않습니다.
