매퍼 XML 의 SQL 에 쓴 칼럼 · 표가 DB 에 없으면 알려 줍니다.

매퍼 실행 창에서 마지막에 고른 접속(없으면 하나뿐인 접속)의 기본 스키마와 비교합니다. DB 에 새로 묻지 않고 이미 읽어 둔 목록만 봅니다: 접속하지 않았으면 아무것도 표시하지 않고, 칼럼은 탐색기에서 펼쳤거나 자동완성이 읽은 표만 검사합니다.

어느 표의 칼럼인지 확실한 것만 봅니다(「별칭.칼럼」, INSERT 칼럼 목록, UPDATE SET, 표가 하나뿐인 문장의 SELECT 목록 · WHERE 조건). ${} 치환 · include · 서브쿼리 별칭 · WITH 이름 · DB 링크 · 다른 스키마의 표는 건너뜁니다.

표 없음은 약한 표시입니다. 동의어와 다른 스키마의 표는 목록에 없어 가릴 수 없으니, 그런 표를 많이 쓰면 아래 설정에서 끄세요. DB 밖에서 표가 바뀌었으면 탐색기에서 새로고침하세요.
