Maven 설정

설정 → 빌드, 실행, 배포 → 빌드 도구 → Maven
오프라인 작업 3
  1. 1
    Maven 은 따로 안 깔아도 됨 번들 Maven 3 을 그대로 씁니다. 회사에서 정한 판이 있으면 그 설치 폴더를 고릅니다.
  2. 2
    이클립스와 같은 두 경로 이클립스 Preferences → Maven → User Settings 의 설정 파일 · 로컬 저장소를 그대로 적고 「재정의」를 켭니다. 이미 받아 둔 jar 를 써서 인터넷을 거의 타지 않고, 사내 mirror 도 settings.xml 에서 따라옵니다.
  3. 3
    오프라인 작업 사내망 밖이거나 저장소에 못 닿을 때 켜면, 로컬 저장소에 있는 것만으로 읽습니다.
  4. ↻
    pom.xml 을 고친 뒤 프로젝트 트리 우클릭 맨 위의 Maven 다시 읽기(고른 프로젝트만). 이클립스 Maven → Update Project 와 같습니다.

Gradle 설정

설정 → 빌드, 실행, 배포 → 빌드 도구 → Gradle
  1. 1
    IDE 가 직접 빌드 원래 인텔리제이는 Gradle 에 맡기지만 EI IDE 는 새 프로젝트를 「IntelliJ IDEA」 로 둡니다. 그래야 저장할 때 자동 빌드가 돌고 서버 재시작이 빠릅니다. 예전에 「Gradle」 로 정해 둔 프로젝트는 여기서 바꿉니다.
  2. 2
    Gradle JVM build.gradle 을 읽을 때 쓰는 자바입니다. 프로젝트 JDK 와 같게 두는 것이 가장 덜 꼬입니다. 설치 3번에서 넣은 Temurin 17 · 21 · 27 이 목록에 있습니다.
  3. G
    사내망에서 wrapper 가 못 받을 때 프로젝트가 Gradle 8.14.6 이면 미리 넣어 둔 것을 그대로 씁니다. 다른 판이면 「Gradle 위치」를 「지정한 위치」로 바꾸고 %USERPROFILE%\.gradle\wrapper\dists\gradle-8.14.6-bin\…\gradle-8.14.6 을 고릅니다.
  4. ↻
    build.gradle 을 고친 뒤 프로젝트 트리 우클릭 맨 위의 Gradle 다시 읽기(전체). 이클립스 Gradle → Refresh 와 같습니다.
  5. i
    모듈이 셋으로 보여도 정상 Gradle 프로젝트는 batch · batch.main · batch.test 로 나뉩니다. 서버 창은 이것을 알아서 한 서버로 묶습니다.

매퍼 XML 문장 옆 ▶select · insert · update · delete 어디서든 커서를 두고 단축키.
→
매개변수 입력비우면 <if> 가 빠집니다. 넣은 값은 문장마다 기억합니다.
→
실제 실행될 SQL<if> · <foreach> 를 풀어 미리 보여 줍니다. 복사도 됩니다.
→
실행결과 창으로. resultType DTO 와 SELECT 칼럼이 안 맞으면 경고.

⑥ SQL 로그 → 실행 SQL Ctrl+Alt+C

서버 콘솔 로그 (우클릭)
==>  Preparing: SELECT * FROM ORDERS WHERE ORDER_NO = ? AND ST = ?
==> Parameters: O100(String), A(String)
값을 채운 SQL
SELECT * FROM ORDERS WHERE ORDER_NO = 'O100' AND ST = 'A'

우클릭 메뉴: 「SQL 로 바꿔 복사」 · 「데이터베이스 콘솔에서 실행」 · 「MyBatis 실행 창으로 열기」.

「쿼리 콘솔로 보내기」는 실행하지 않고 콘솔에 붙입니다. 로그가 아닌 선택 글도 그대로 보냅니다.

⑦ 매퍼 뼈대 · DTO · ERD

매퍼 뼈대 만들기

표 우클릭 → resultMap · select · insert · update · delete · 인터페이스. 구식 조인, 부등호 CDATA, WHERE 1 = 1, 표 · 칼럼 이름 대문자 · 별칭 소문자. 있는 파일은 덮어쓰지 않고 덧붙입니다.

DTO 만들기

결과 창 「DTO 만들기」 → 결과 칼럼으로 자바 DTO 와 resultMap. 칼럼 이름은 낙타 표기 필드로.

ERD

표 카드(한글 주석) + FK 선. 끌어 옮기기 · 확대 · PNG 저장, 카드 더블클릭 → 데이터 보기.
