# 노트북에서도 빌드하기

데스크탑(`D:\myide`)과 노트북 어느 쪽에서 빌드해도 소스와 판 번호가 하나로 이어지게 하는 방법입니다.
소스 · 우리 플러그인 jar · 설명서는 깃이 맞춰 주고, 판 번호는 `build-windows.bat` 이 GitHub 마지막 릴리스 다음 번호로 매깁니다.
깃에 안 올라가는 무거운 폴더만 처음 한 번 데스크탑에서 복사해 오면 됩니다.

## 처음 한 번 (노트북 준비)

1. 프로그램 설치
   - Git, Python 3.12, GitHub CLI(`winget install GitHub.cli`)
   - 플러그인을 직접 컴파일할 때만: JDK 21 이상
   - 메모리 16GB 이상, 여유 디스크 50GB 이상
2. 데스크탑의 `D:\myide` 를 외장 디스크 등으로 노트북에 통째로 복사합니다. 경로는 같게(`D:\myide`) 두는 것이 편하고, D 드라이브가 없으면 `C:\myide` 처럼 공백 · 한글 없는 곳에 둡니다.
   - 빼도 되는 것: `backup\` · `logs\` · `tmpjars\` · `intellij-community-new\` · `release\*.exe`
   - 꼭 있어야 하는 것(깃에 없음):

     | 폴더 | 내용 | 없으면 |
     |---|---|---|
     | `.git\` | 깃 기록과 설정(`core.autocrlf false`) | 새로 clone 하면 `.bat` 줄끝이 바뀔 수 있음 |
     | `intellij-community\` | 받은 IntelliJ 소스 + android 모듈 + kit 적용분 | `get-source.bat`(10~30분)부터 다시 |
     | `bundled-plugins\` 의 받아 둔 외부 플러그인(fullLine · intellij-rainbow-brackets-lite · pojo2json · GrepConsole 등) | 본체에 함께 들어가는 외부 플러그인 | 노트북 빌드에서 그 플러그인이 빠짐 |
     | `release\plugins\` | `플러그인설치.bat` 이 넣는 한국어 팩 | 노트북에서 만든 설치본에 한국어 팩을 못 넣음 |

3. 노트북 cmd 에서 한 번:
   ```
   cd /d D:\myide
   git status
   gh auth login
   ```
   `git status` 가 깨끗해야 합니다. `gh auth login` 은 판 번호 읽기와 릴리스 올리기에 필요합니다.

외부 플러그인을 한쪽 PC 에서 새로 받거나 판을 올렸으면 그 폴더를 다른 PC 에도 다시 복사합니다(깃이 옮겨 주지 않습니다).

## 빌드할 때마다 (어느 PC 든)

1. `git pull` — 다른 PC 에서 올린 변경을 받습니다.
2. CLAUDE.md 「빌드」 순서대로 kit 적용 후 `build-windows.bat`.
   - 판 번호는 GitHub 마지막 릴리스 번호 + 1 입니다(이 PC 의 `build-number.txt` 가 더 크면 그 다음). 인터넷이 안 되거나 gh 로그인이 안 돼 있으면 이 PC 기록만 보고 매기므로 다른 PC 와 겹칠 수 있습니다.
   - 실패하거나 중간에 멈춘 빌드는 번호를 쓰지 않습니다. 다음 빌드가 같은 번호를 씁니다.
3. 이 PC 에서 고친 것이 있으면 `git add` · `git commit` · `git push`.
4. 다른 PC 로 옮기면 1번(`git pull`)부터.

## 주의

- 두 PC 에서 동시에 빌드하면 같은 번호가 나옵니다. 나중에 끝난 쪽은 GitHub 릴리스 올리기가 실패하니(같은 태그), 그때는 다시 빌드합니다.
- Claude 원격 세션에서 빌드할 때 `NoDefaultCurrentDirectoryInExePath=1` 이 걸려 있으면 빌드가 깨집니다. `set NoDefaultCurrentDirectoryInExePath=` 로 풀고 돌립니다.
- `python` 이 스토어 안내 창을 띄우면 `py -3` 이나 설치 경로(`%LOCALAPPDATA%\Programs\Python\Python312\python.exe`)로 돌립니다.
- 시험용 사용자 플러그인 폴더(`%APPDATA%\JetBrains\EIIDE2026.2\plugins`)는 PC 마다 따로입니다. 빌드에는 쓰지 않습니다.
